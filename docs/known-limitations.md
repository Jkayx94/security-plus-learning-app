# Known Limitations
- The offline Ask AI tutor is deterministic and curriculum-grounded; it is not a generative cloud model.
- Full handcrafted prose and bespoke PBQ artwork for all 914 records would require ongoing editorial production; this release generates consistent learning and assessment paths from approved metadata.
- Browser storage is device/profile specific until optional cloud sync is added.
- Automated tests validate data and build integrity; physical Samsung-device testing must be completed after deployment.
- Exam readiness is an estimate, not a guarantee.
