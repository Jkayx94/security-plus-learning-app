# Android Update Instructions
1. Deploy to GitHub Pages.
2. Open the Pages URL in Chrome on Android.
3. Open the installed PWA once while online.
4. Reload when the update prompt appears, or close and reopen twice.
5. Confirm version 2.0.0 in the header.
6. Verify Learn shows 101 units and Acronym trainer shows 336 records.
7. Turn on airplane mode and reopen to test offline launch.
8. Export a backup after confirming migrated progress.
